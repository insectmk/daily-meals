# 规范

记录项目规范，保证代码可读性、可维护性，提升代码质量

### 提交信息

提交信息需要按照规范提交，提交格式如下：

```tex
<类型>(<范围>): <简短描述>

<详细描述>

<关联的任务或问题>
```

**示例**

```tex
feat(认证): 添加用户登录功能

实现了用户登录功能，包括邮箱和密码验证。优化了登录页面的用户体验。

Closes #123
```

**提交类型**

| 修改类型 | 提交类型   | 示例                                                         |
| -------- | ---------- | ------------------------------------------------------------ |
| 新功能   | `feat`     | `feat(用户模块): 添加用户登录功能` <br/>`feat(订单模块): 新增订单创建功能`<br/>`feat(支付模块): 添加支付功能`<br/>`feat(商品模块): 新增商品搜索功能` |
| Bug 修复 | `fix`      | `fix(登录页面): 修复无法提交的问题`<br/>`fix(支付模块): 修复支付失败的错误`<br/>`fix(订单模块): 修复订单状态更新问题`<br/>`fix(商品模块): 修复商品详情页显示错误` |
| 性能优化 | `perf`     | `perf(数据库): 优化查询性能`<br/>`perf(前端H5): 优化页面加载速度`<br/>`perf(API): 优化接口响应时间`<br/>`perf(缓存): 优化缓存命中率` |
| 代码样式 | `style`    | `style(全局): 格式化代码，调整缩进`<br/>`style(登录页面): 调整按钮样式`<br/>`style(订单页面): 调整表格样式`<br/>`style(支付页面): 优化输入框样式` |

| 测试相关 | `test`     | `test(用户模块): 添加登录功能单元测试`<br/>`test(订单模块): 添加订单创建集成测试`<br/>`test(支付模块): 添加支付功能测试`<br/>`test(商品模块): 添加商品搜索功能测试` |

| CI 配置  | `ci`       | `ci(GitHub Actions): 添加自动化测试流程`<br/>`ci(GitLab CI): 优化构建脚本`<br/>`ci(Jenkins): 优化部署流程`<br/>`ci(Travis CI): 添加代码质量检查` |
