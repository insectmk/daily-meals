# 框架使用

## 数据库字段保存多值

比如，商品字段需要存储该商品的轮播图，有很多张图片，可以存储在一个varchar字段中，存储URL的JSON数组字符串

```json
["http://127.0.0.1:9005/daily-meals/288090b1de127bb524731f04872ba0ee0b7bcb67a33d67af468219bbc10876d0.jpg","http://127.0.0.1:9005/daily-meals/415c1f6e864006b169405c96b0af0811b6aa0bc127505f0dbd2d145593979b73.jpg"]
```

要完成该功能，只需要在后端简单设置几步，然后前端传递这个JSON数组字符串即可。

1. 编辑`DO`、`VO`（这里只展示DO，VO加上该属性即可）：

   ```java
   @TableName(value = "t_xxxx", autoResultMap = true)
   public class XXXXDO extends BaseDO {
   	/**
   	* 省略其他字段
   	*/
       
       /**
        * 轮播图
        */
       @TableField(typeHandler = JacksonTypeHandler.class)
       private List<String> sliderPicUrls;
   
   }
   ```

   其中，重要的就是两个注解

   1. `@TableName(value = "t_xxxx", autoResultMap = true)`：加上了`autoResultMap`
   2. `@TableField(typeHandler = JacksonTypeHandler.class)`：JSON解析字段

2. 编辑前端，传递数组字符串，可自行解析
